# Galería de cumpleaños — versión sencilla

No necesitas editar las rutas de las fotografías.

## Paso 1: usa esta estructura exacta

```text
galeria-cumpleanos/
├── index.html
├── style.css
├── script.js
└── images/
    ├── foto_1.jpeg
    ├── foto_2.jpeg
    ├── foto_3.jpeg
    ├── foto_4.jpeg
    ├── foto_5.jpeg
    ├── foto_6.jpeg
    ├── foto_7.jpeg
    ├── foto_8.jpeg
    ├── foto_9.jpeg
    ├── foto_10.jpeg
    ├── foto_11.jpeg
    └── foto_12.jpeg
```

Los nombres deben coincidir exactamente, incluyendo el guion bajo y `.jpeg`.

## Paso 2: abre la página

1. Abre la carpeta completa en Visual Studio Code.
2. Haz clic derecho sobre `index.html`.
3. Selecciona **Open with Live Server**.

No tienes que modificar `script.js`. La página busca automáticamente las doce
fotografías.

## Personalizar los textos

Abre `index.html` y cambia:

- `DS` por las iniciales de la persona.
- `Recuerdos · 2026` por el año correspondiente.
- El título principal.
- El mensaje que aparece al final.

## Si una fotografía no aparece

Comprueba que:

- La carpeta se llame exactamente `images`.
- El archivo sea realmente `.jpeg`, no `.jpg`.
- No existan espacios en el nombre.
- La numeración sea `foto_1.jpeg` hasta `foto_12.jpeg`.
